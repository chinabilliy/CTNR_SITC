短租箱 EIR 生成系统 —— 服务器部署说明
========================================

★ 如果不想安装 Python，请直接用「免安装 exe 版」：
   双击 短租箱EIR系统.exe 即可运行，详见同目录 exe使用说明.txt。
   免安装版数据落在 exe 旁边的 data\eir.db，与下面的 Python 版完全兼容。
   以下内容适用于需要用 Python 源码方式运行的场景。

一、环境要求
  1. Python 3.9 或更高版本（Windows 安装时务必勾选 "Add python.exe to PATH"）
  2. 服务器可访问外网（用于安装 Python 依赖）；若离线，请预先安装：
     flask  waitress  openpyxl  python-docx

  Windows 提示：
     start.bat 会自动查找可用 Python（py 启动器、PATH、常见安装目录）。
     若窗口提示 "Python 3.9+ was not found"，说明本机尚未安装 Python，
     请到 https://www.python.org/downloads/ 下载安装，
     安装第一步务必勾选 "Add python.exe to PATH"，装完重新运行 start.bat。

  Linux 提示：
     先确认已安装：python3 --version
     若未安装（以 Ubuntu/Debian 为例）：sudo apt install python3 python3-pip

二、启动
  Linux / macOS：
      chmod +x start.sh
      ./start.sh

  Windows：
      双击 start.bat

  默认监听 0.0.0.0:8888，用浏览器访问：
      http://服务器IP:8888

  自定义端口（例如 9000）：
      Linux:    PORT=9000 ./start.sh
      Windows:  先执行 set PORT=9000，再运行 start.bat

三、默认账号（首次登录后请尽快修改密码）
      admin / admin123    管理员（全部功能）
      front / front123    前台录入 + EIR 打印（合并角色）
      print / print123    打印员

四、目录说明
      app/data/eir.db       SQLite 数据库（本包已含当前主数据与业务数据）
      app/uploads/          上传的放箱图片（按提单号分目录）
      app/backups/          每次放箱/重置前自动生成的数据库备份
      app/excel_templates/  Excel 导入模板
      app/static/eir_assets/ 四种堆场的 EIR 底图

五、恢复到空白数据（重新开始）
  1. 停止服务
  2. 删除 app/data/eir.db
  3. 执行：
         python -m app.seed --import-excel
     该命令会建表、创建上述三个默认账号，并从 宁波FREEUSE提箱.xlsx 导入
     堆场、起租号批次与提箱登记。

六、注意事项
  1. 服务器防火墙需放行 8888 端口（TCP）。
  2. 若 8888 已被其它服务占用，用上面的 PORT 方式换端口。
  3. 生产环境建议修改 app/config.py 中的 SECRET_KEY 为随机字符串，
     修改后需重启服务，已登录用户会失效需重新登录。
  4. 数据库为单文件 SQLite，请定期备份 app/data/eir.db。
  5. 打印 EIR 请用 Chrome / Edge，纸张 A4、缩放 100%，一页一箱。

七、常见问题
  1. 双击 start.bat 窗口一闪而过
     说明本机没有可用的 Python，或 Python 未加入 PATH。
     可先打开命令行，进入本目录执行 start.bat，查看具体报错。

  2. 本机能打开 http://localhost:8888，其它电脑打不开
     - 确认访问的是本机局域网 IP（命令行执行 ipconfig 查看 IPv4 地址）
     - 确认防火墙放行 8888 端口。管理员命令行执行：
         netsh advfirewall firewall add rule name="ShortLeaseEIR8888" dir=in action=allow protocol=TCP localport=8888

  3. 提示端口被占用
     换一个端口：先执行 set PORT=9000，再运行 start.bat。

  4. 启动窗口不能关闭
     start.bat 的窗口就是服务进程，关闭即停止服务。需要常驻可注册为 Windows 服务或使用计划任务。
